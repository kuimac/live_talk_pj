# 判断を残すライブ 企画書 要約

フリーランスエンジニアのライブトークを収益につなぐ企画。2024〜2025年のオープンチャットとライブトークの記録を反映した改訂版（2026年11月3日）。

## 方針

オープンチャットは、気軽に質問でき、匿名でも本音が出る**無料の入口**のままにする。ライブは体験談と意見が交わる場にする。最初の売上は、講師・教材・実践・成果物がある**少人数の勉強会**に置く。協賛金額は、参加人数と反応が貯まってから上げる仮説とする。

伸びる話題は技術情報だけではない。フリーランスの人生、お金、仕事、AI、人間関係を自分の経験として話せるときに会話が続く。優先順位は投稿数の厳密な順位ではなく、反応の質から見た企画順。

強いテーマでは同時に起きる。

- 自分の経験を話したくなる
- 他の人の意見を聞きたくなる
- 自分の状況と比較したくなる
- 少し反論したくなる
- 最後に笑える

1回のライブの使い方は次の順。

1. **無料ライブ** — 話題を作り、信頼を残す
2. **翌日の要約** — 証拠になり、次回の集客になる
3. **実践勉強会** — 最初の売上にする
4. **協賛と交流会** — 企業と参加者が顔を合わせる場にする

月額会員と個人向けの壁打ちは、有料の勉強会が続いたあとに検討する。第1期のライブの最後で案内する商品は、次回ライブか勉強会の申込のどちらか一つ。

## 人気が期待できる話題

上位ほど収益の入口に近い。1〜3位は勉強会と協賛に直結し、4〜7位は参加者と継続を作る。

| 順位 | 話題 | 記録に残った反応 | 最初に投げる問い |
| --- | --- | --- | --- |
| 1 | 生成AI、エージェント、エンジニアの将来 | 2025年7月のライブで Claude、PC操作、MCP、価値がコードから上流へ移るかが話題に。差分確認・テスト・修正を先に Markdown で見る方法まで議論が続いた | 業務で何時間短縮できたか。任せて大失敗した経験はあるか。単価を維持するために何を学ぶか |
| 2 | 年収、単価、税金、お金 | 2025年2月に確定申告の所得アンケート。年収1,500万円の手取りや2,000万円の難しさも。2024年7月は経費から家賃按分、飲食、税理士、オフ会費用へ広がり冗談の掛け合いに | 売上と手取りの差に驚いた経験はあるか。月単価100万円は会社員の年収1,000万円より幸せか。独立後、後悔したお金の使い方は何か |
| 3 | 案件獲得、営業、契約、エージェント | 2024年1月、社員5人の会社が受託を始める営業先と SNS の DM。2025年9月30日はエージェント以外で案件を取る人の明暗 | 直請けの最初の1件はどう取ったか。エージェントと直請けで手取りはどれだけ違うか。明日案件が終わったら次をどう探すか |
| 4 | キャリアと人生。会社員とフリーランス | 2024年7月、エンジニア人生を下積み・フリーランス・フルリモートの章に分けて語る会話。働く目的、お金、自由な時間、将来の夢へ | 一番つらかった現場はどこか。今の働き方を10年続けられるか。月収が半分でも自由が増えるなら移るか |
| 5 | コミュニティ、オフ会、人脈 | 2025年9月、勉強会が成長にどれだけ効くか。10月にはオフ会参加の心理的ハードルの言語化まで | オフ会で人生が変わった経験はあるか。人脈から仕事につながったことはあるか。初参加で一番不安だったことは何か |
| 6 | 道具、趣味、生活、お金の使い方 | 2024年6月に休日・趣味・私生活・お金の使い方のライブを企画。5月は15万円のサーキット体験から各自の良い経験の紹介へ | 独立後、一番高かった買い物は何か。仕事道具にいくら使っているか。使って本当に良かった経験は何か |
| 7 | 大喜利、雑談、理想と現実 | 2024年12月27日は5時間。資格、セキュリティ、経営、AI、性格診断、AI大喜利まで。2025年1月1日は理想と現実の対比に自虐の返事 | 想像と違ったこと選手権。現場で見た一番謎なルールは何か。AIに絶対任せたくない仕事は何か |

返しは「AIはすごい」「お金は大事」で止めない。技術派と慎重派、成功談と失敗談の両方に振る。数字が出ると具体になる。所得や資産の実額をその場で公開するよう求めない。経費の話では、税務上の判断とネタとしての冗談を分けて言う。

## 盛り上がる反応と返し方

ログに繰り返し出る反応は7つ。

| 反応 | 具体例 | 効果 |
| --- | --- | --- |
| 自分の体験談 | 自分はこうだった | 発言する人が増える |
| 数字を出す | 月単価、年収、経費 | 話が具体になる |
| 反論、異論 | それは違うと思う | 議論が続く |
| 失敗談 | 実は失敗した | 共感が生まれる |
| 自虐、冗談 | エンジニアあるある | 空気が和む |
| 深掘り | なぜそう思ったか | 同じ話題が長く続く |
| 二択、投票 | AとBのどちらですか | 最初の一言が出やすくなる |

1回の中での進行。

1. 問いを投げる（例：AIでエンジニアの仕事は減るか）
2. 具体例を求める（例：実際に仕事が減った人はいるか）
3. 反対側も拾う（例：AIのおかげで仕事が増えた人はいるか）
4. 運営が一言で整理する（例：実装は減り、設計とレビューは増える、という意見が並んだ）
5. 次の問いに渡す（例：今から学ぶなら何を優先するか）

運営者が自分の結論を長く話すより、出た発言を拾って別の参加者に振ると会話が続く。意見が分かれても人格の話にしない。論点を短く言い直して次の人へ渡す。ライブの最後の3分は、その回の出口を一つだけ案内する。

## 収益の置き方

オープンチャット自体を先に有料にしない。料金が付くのは、無料の雑談では手に入らない体験。

| 商品 | 中身 | 初期価格 | 位置づけ |
| --- | --- | --- | --- |
| AI・技術の勉強会 | Claude Code 実践、MCP、エージェント、業務の自動化。講師、教材、手を動かす時間、成果物がある | 1人 3,000〜8,000円。20人で6万〜16万円 | **最優先**。2025年7月に Claude MCP の勉強会を開き、参加募集への反応があった |
| 協賛 | ライブのゲスト、提供の勉強会、製品の体験会、採用や案件紹介のイベント。対象はエージェント、受託会社、AIツール、クラウド、税理士・会計 | 1回 3万〜10万円で提案し、反応を見て上げる | 実績がない段階の仮説。人数、属性、反応が貯まってから単価を上げる |
| 有料の交流会 | 経営者とフリーランス、直請けを持つ会社との交流、少人数の技術相談、開発合宿 | 1人 3,000〜5,000円。20人で6万〜10万円。飲食と会場は別 | オフ会の話題がすでにあるので、無料の雑談の次に置ける |
| 月額会員 | 月1回の少人数相談、限定ライブ、勉強会の資料、営業とキャリアの相談 | 月額 980〜2,980円。50人で月4.9万〜14.9万円 | 勉強会が2回売れてから文面を作る。第1期の途中では募集しない |
| 企業との接点 | 企業が案件情報を出し、希望者が面談する。協賛やイベント費として受け取る形もある | イベント費として設計する | 職業紹介や募集情報の提供にあたるかは、始める前に法令と届出を確認する |

個人向けの壁打ち（60分・1万円）と顧問（月5万円、月1回、3か月）は残す。案内を始めるのは、勉強会の参加者が「自分の案件を見てほしい」と言い始めてから。経理は既存の個人事業の請求に載せる。見積・請求・振込先のひな形は第1回の前に1種類作る。

## 最初の1か月

月額会員から始めない。無料ライブで話題を作り、4週目までに勉強会を1回売る。

| 週 | 企画 | 目的 | 最後に案内するもの |
| --- | --- | --- | --- |
| 1 | AIでエンジニアの仕事はなくなるか | 話題を作り、人を集める | 次回ライブ |
| 2 | フリーランスの年収と手取り | お金への関心の強さを見る | 次回ライブ |
| 3 | Claude Code 実践勉強会 | 最初の売上 | 勉強会の申込 |
| 4 | 直請けと営業のリアル | 協賛できる相手を見つける | 勉強会の残席。協賛の打診はライブの外で行う |

役割の分け方。

- 無料ライブは雑談、体験談、意見交換
- 有料イベントは講師、教材、実践、成果物
- 協賛は企業との接点、採用、製品の体験

2週目まで申込がゼロでも、3週目の勉強会は少人数で実施する。定員は8人から始め、価格は1人5,000円を初期値にする。

## ライブ企画10本

告知にそのまま使える題。第1弾から第4弾を最初の1か月に使う。

| 回 | タイトル | 核になる問い |
| --- | --- | --- |
| 1 | AIでエンジニアは失業するのか | 仕事がなくなる人と、稼げる人の違いは何か |
| 2 | 年収と手取りのリアル | 売上1,000万円でも、自由に使えるお金はいくらか |
| 3 | エージェントを使わず案件を取る | 直請けの最初の1件を、どうやって取ったか |
| 4 | 月単価100万円の壁 | 80万円から100万円へ上げるには何が要るか |
| 5 | 会社員に戻りたいと思った瞬間 | フリーランスになって後悔したことはあるか |
| 6 | AIに仕事を奪われる職種 | 実装、テスト、デザイン、インフラ。影響が大きいのはどれか |
| 7 | エンジニアの人生設計 | 50歳のとき、まだコードを書いていたいか |
| 8 | 経費はどこまで認められるか | PC、家賃、飲食、旅行。自分の線引きはどこか。判断と冗談は分ける |
| 9 | 失敗談選手権 | 今なら笑える、現場での失敗は何か |
| 10 | 働かなくてよくなったら何をするか | 資産が十分にあると仮定したら、仕事を続けるか。実額は聞かない |

### 第1弾の告知文

最初に出す告知は第1弾のAI回。絵文字は使わず、このまま投稿できる。

> 今週のライブトークのお知らせ
>
> **AIでエンジニアは失業するのか**
>
> Claude、ChatGPT、Cursorなど、AIの開発ツールが急速に進んでいます。コードを書かせるだけでなく、アプリ開発やPC操作まで任せられるようになってきました。今回は、皆さんの実体験を聞きたいと思います。
>
> 話したいこと
>
> - 仕事は減ったか、増えたか
> - 単価は上がったか
> - 仕事を任せることへの不安
> - 5年後に必要な技能
> - 今から学ぶなら何を選ぶか
>
> 肯定する人も、慎重な人も歓迎です。正解を決める場ではありません。使っている人、まだ使っていない人、これから学びたい人も参加できます。聞くだけの参加も歓迎です。

## すでにある場の使い方

| 場 | いまの役割 | 収益までの使い方 |
| --- | --- | --- |
| フリーランスエンジニアのオープンチャット | 質問、技術、雑談、案件の情報が日常的に交わる入口 | 無料のまま。ライブの告知と勉強会の募集だけを置く |
| X（ライブトークの発信） | 告知、議論の要約、次回テーマの投票、参加者の募集 | ライブの翌日に要約を出し、反応が大きかった問いを次の題にする |
| ライブトークとイベント | 無料の交流の本編 | 有料の勉強会、協賛、リアルの交流会への出口を一つずつ付ける |

## 1回のライブを資産にする

雑談で終わらせず、同じ回から翌週までの素材を作る。

| 曜日 | やること |
| --- | --- |
| ライブ当日 | 問い、具体例、反対意見、整理、次の問い、の順で進める |
| 翌日 | 盛り上がった話題を3つに要約し、チャットとXに出す |
| その翌々日まで | 反応が大きかった話題を、短い記事にする |
| 週の終わり | 次回の題を投票で決める。協賛の営業には、その週の関心を1枚にまとめて添える |

企業へ出す材料は「フリーランスのエンジニアが、今どの話題に時間を使っているか」。再生数ではなく、発言数、投票数、勉強会の申込数を添える。

## 90日の進め方

**開始前**

- 第1弾の告知を、オープンチャットとXに出す
- 勉強会の1枚を作る。題は Claude Code 実践、定員8人、5,000円、成果物は自分の作業を1つ自動化した記録
- 協賛の仮説を1枚にする。1回3万円から試し、提供内容はゲスト15分と参加者への紹介まで
- 申込フォームは名前、参加目的、支払い方法。請求のひな形を1種類用意する

**1〜4週**

- 最初の1か月の4本を、週1で実施する
- 各回の翌日に要約を3点出す
- 3週目に勉強会を実施する。申込が3人未満でも開き、内容を短くして記録を残す
- 4週目のあと、協賛できそうな相手を3つ書き、ライブの外で1社に送る

**5〜8週**

- 発言と投票が多かった題で、ライブをもう4回行う
- 勉強会を2回目開く。1回目の成果物を告知に使う
- 2回合計の申込が6人未満なら、価格を3,000円にするか、題をAI以外の上位話題（お金、案件）に変える。週1のライブは続ける

**9〜12週**

- 協賛を1回実施するか、実施日を決める
- 月額会員の文面は、勉強会が2回売れてから書く
- 案件の仲介は、法令と届出の確認が終わるまで開始しない
- 91日目に、話題別の発言数、勉強会の人数と売上、協賛の打診数を1枚にまとめる

## 成果指標

| 時点 | 見る数字 | 継続の判断 |
| --- | --- | --- |
| 毎週 | 参加人数、発言数、投票数。翌日の要約を出したか | 要約が2週続かなければ、3点・各2行までに短くして続ける |
| 4週 | 勉強会の申込と実施、協賛候補のリスト | 勉強会を1回実施し、候補を3つ書く |
| 8週 | 勉強会2回の合計人数と売上 | 合計6人未満なら、価格か題を変えて3回目を行う |
| 91日目 | どの商品にお金が乗ったか | 勉強会が売れていればそれを本線にする。協賛が先に決まれば、勉強会と交互に置く |

再生回数と登録者数は記録するが、第1期の合否には使わない。

## リスクと線引き

| 起きうること | 扱い |
| --- | --- |
| 所得や資産を聞きすぎる | 範囲で聞く。実額の公開は本人の意思に任せる。第10弾は仮定の話にする |
| 税金の雑談が助言に聞こえる | 経験談と冗談だと先に言う。正しい判断は税理士に渡す、と毎回添える |
| 意見の対立が人格の話になる | 論点を一言で言い直し、次の人に振る。運営は判定者にならない |
| 無料の場を有料で囲う | オープンチャットとライブの雑談は無料のまま。料金は実践、資料、対面、企業との接点に付ける |
| 協賛金額を先に高く置く | 3万〜10万円は仮説。1回実施した人数と反応を見てから上げる |
| 案件紹介が仲介事業になる | 対価を得て仕事をあっせんする前に、法令と届出を確認する。確認前はイベントの協賛までに留める |
| 準備が受託の稼働を圧迫する | ライブの準備は60分まで。10本の題は開始前にこの企画書で確定している |

## 今週やること

1. 第1弾の告知を、オープンチャットとXに出す
2. 第1回の進行を、問い・具体例・反対意見・整理・次の問い、の5行で書く
