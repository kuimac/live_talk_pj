# 判断を残すライブ 企画書

フリーランスエンジニアのライブトークを、収益につなぐ。

2024〜2025年のオープンチャットとライブトークの記録を反映。2026年11月3日。

オープンチャットは、気軽に質問でき、匿名でも本音が出る無料の入口のままにする。ライブは体験談と意見が交わる場にする。最初の売上は、講師・教材・実践・成果物がある少人数の勉強会に置く。協賛の金額は、参加人数と反応が貯まってから上げる仮説とする。

---

## 1. 結論

伸びる話題は、技術情報だけではない。フリーランスの人生、お金、仕事、AI、人間関係を、自分の経験として話せるときに会話が続く。

優先順位は投稿数の厳密な順位ではない。反応の質から見た企画順である。上位ほど収益の入口に近い。1位から3位は勉強会と協賛に直結し、4位から7位は参加者と継続を作る。

第1期の90日でやることは、次の3つに限る。

1. 週1の無料ライブ
2. 翌日の3点要約
3. 1人5,000円、定員8人の勉強会

月額会員と、個人向けの壁打ちは、勉強会が2回売れたあとに文面を作る。第1期のライブの最後で案内する商品は、次回ライブか勉強会の申込、どちらか一つにする。

90日の合格線は、勉強会の累計売上が5万円以上であること。定員まで埋まった場合の見方は、2回 × 8人 × 5,000円 = 8万円。5人 × 2回 × 5,000円 = 5万円。協賛は別枠で、決まらなくても勉強会は続ける。

## 2. 誰に届けるか

届ける相手は、フリーランスのエンジニアと、独立を考えているエンジニア。

すでに持っている入口は3つ。

| 場 | いまの役割 | 収益までの使い方 |
| --- | --- | --- |
| フリーランスエンジニアのオープンチャット | 質問、技術、雑談、案件情報が日常的に交わる入口 | 無料のままにする。ライブの告知と、勉強会の募集だけを置く |
| X（@free_eng_live） | 告知、議論の要約、次回テーマの投票、参加者の募集 | ライブの翌日に要約を出し、反応が大きかった問いを次の題にする |
| ライブトーク | 無料の交流の本編 | 有料の勉強会、協賛、リアルの交流会への出口を一つずつ付ける |

オープンチャットでの宣伝は、毎回の告知を重ねるより、普段の会話と役立つ情報を先にする。告知はライブの案内と、勉強会の募集に限る。

## 3. 会話が続く条件

強いテーマでは、次のことが同時に起きる。

- 自分の経験を話したくなる
- 他の人の意見を聞きたくなる
- 自分の状況と比較したくなる
- 少し反論したくなる
- 最後に笑える

返しは「AIはすごい」「お金は大事」で止めない。技術派と慎重派、成功談と失敗談の両方に振る。数字が出ると具体になる。所得や資産の実額を、その場で公開するよう求めない。経費の話では、税務上の判断と、ネタとしての冗談を分けて言う。

運営者が自分の結論を長く話すより、出た発言を拾って別の参加者に振ると会話が続く。意見が分かれても、人格の話にしない。論点を短く言い直して次の人へ渡す。

## 4. 集客に使うテーマ

### 1位　生成AI、エージェント、エンジニアの将来

最初の売上にする題。

2025年7月1日のライブで、Claude、PC操作、MCP、価値がコードから上流へ移るかが話題になった。その後も、差分確認、テスト、修正を先に Markdown で見る方法まで議論が続いた。

最初の問い：業務で、AIに任せて何時間短縮できたか。

このあと返す順：

1. 任せて、大失敗した経験はあるか。
2. 仕事が減った人と、増えた人。両方いるか。
3. 単価を維持するために、今何を学んでいるか。
4. 実装は減って、設計とレビューが増える。この整理で合っているか。

商品：Claude Code 実践。定員8人。1人5,000円。成果物は、自分の作業を1つ自動化した記録。

### 2位　年収、単価、税金、お金

人は集まる。第1期の商品にはしない。

2025年2月に確定申告の所得アンケートがあり、売上と所得の違いも確認された。年収1,500万円の手取りや、2,000万円の難しさも話された。2024年7月は経費から家賃按分、飲食、税理士、オフ会費用へ広がり、冗談の掛け合いになった。

最初の問い：売上と手取りの差に、驚いたことはあるか。

このあと返す順：

1. 月単価100万円は、会社員の年収1,000万円より幸せか。
2. 独立して、後悔したお金の使い方は何か。
3. 法人化して楽になったことと、面倒になったことを一つずつ。
4. 数字は範囲で聞く。実額の公開は本人の意思に任せる。

税金の話は経験談だと先に言い、判断は税理士へ渡す。

### 3位　案件獲得、営業、契約、エージェント

協賛の相手が見える題。

2024年1月、社員5人の会社が受託を始める営業先と、SNSのDMについて具体的なやり取りがあった。2025年9月30日のライブは、エージェント以外で案件を取る人の明暗が議題だった。

最初の問い：直請けの最初の1件は、どう取ったか。

このあと返す順：

1. エージェントと直請けで、手取りはどれだけ違うか。
2. 単価交渉で通った話と、落ちた話。両方聞く。
3. 明日、案件が終わったら、次をどう探すか。
4. 成功だけで止めず、失敗の条件を一つ聞く。

協賛の打診はライブの外で行う。1回3万円、ゲスト15分と参加者への紹介から試す。仕事のあっせんは、法令と届出の確認が終わるまで始めない。

### 4位　キャリアと人生。会社員とフリーランス

部屋を残す題。勉強会の申込には直結しにくい。要約して翌日に出すと、次回の参加理由になる。

2024年7月1日、エンジニア人生を下積み、フリーランス、フルリモートの章に分けて語る会話があった。働く目的、お金、自由な時間、将来の夢へ広がった。

最初の問い：今の働き方を、あと10年続けられるか。

このあと返す順：

1. 一番つらかった現場はどこか。
2. 月収が半分でも自由が増えるなら、移るか。
3. エンジニアを辞めるなら、次は何をするか。
4. 正解は出さない。条件の違う人に、同じ問いを渡す。

### 5位　コミュニティ、オフ会、人脈

有料の交流会の前に置く。第1期の本線は勉強会のままにする。

2025年9月30日のライブで、勉強会が成長にどれだけ効くか、何を得たかが話された。10月には、オフ会に参加する心理的なハードルの言語化まで進んだ。

最初の問い：オフ会で、仕事か人生が動いた経験はあるか。

このあと返す順：

1. 人脈から仕事につながったことはあるか。
2. 初参加で、一番不安だったことは何か。
3. オンラインとリアル、今はどちらが役に立っているか。
4. 参加できない理由も、参加した理由と同じ重さで拾う。

交流会を始めるときの価格は、1人3,000〜5,000円。飲食と会場は別。第1期の90日には入れない。

### 6位　道具、趣味、生活、お金の使い方

空気を温める題。固い回の前後に置くと、次の発言が出やすくなる。

2024年6月に、休日・趣味・私生活・お金の使い方を扱うライブが企画された。5月には15万円のサーキット体験への投資から、各自の良い経験の紹介へ広がった。

最初の問い：独立してから、一番高かった買い物は何か。

このあと返す順：

1. 仕事道具に、いくら使っているか。
2. 使って、本当に良かった経験は何か。
3. フリーランスになって、趣味は増えたか。
4. 金額の自慢で止めず、その出費のあと何が変わったかを聞く。

### 7位　大喜利、雑談、理想と現実

人が残る題。商品はその場で売らない。笑いで終わった一言は、翌日の要約の見出しにする。

2024年12月27日のライブは5時間になり、資格、セキュリティ、経営、AI、性格診断、AI大喜利まで広がった。2025年1月1日には、理想と現実の対比に自虐の返事が返った。

最初の問い：フリーランスになって、想像と違ったことを一言で。

このあと返す順：

1. 現場で見た、一番謎なルールは何か。
2. AIに、絶対任せたくない仕事は何か。
3. 理想のエンジニア生活を、現実と比べて一言で。
4. その一言を、翌日の要約の見出しにする。

## 6. 1回の進行

1回のライブは、次の5手で進める。

| 手 | やること | AI回での例 |
| --- | --- | --- |
| 1 | 問いを投げる | AIで、エンジニアの仕事は減るか。 |
| 2 | 具体例を求める | 実際に仕事が減った人はいるか。 |
| 3 | 反対側を拾う | AIのおかげで仕事が増えた人はいるか。 |
| 4 | 一言で整理する | 実装は減り、設計とレビューは増える、という意見が並んだ。 |
| 5 | 次の問いに渡す | 今から学ぶなら、何を優先するか。 |

ライブの準備は60分まで。最後の3分は、その回の出口を一つだけ案内する。

1回のライブから、翌週までの素材を作る。

| タイミング | やること |
| --- | --- |
| 当日 | 問い、具体例、反対意見、整理、次の問い、の順で進める |
| 翌日 | 盛り上がった話題を3つに要約し、チャットとXに出す。各2行まで |
| その翌々日まで | 反応が大きかった話題を、短い記事にする |
| 週の終わり | 次回の題を投票で決める。協賛の営業には、その週の関心を1枚にまとめて添える |

企業へ出す材料は「フリーランスのエンジニアが、今どの話題に時間を使っているか」である。再生数ではなく、発言数、投票数、勉強会の申込数を添える。

## 8. 最初の90日

月額会員から始めない。無料ライブで話題を作り、4週目までに勉強会を1回売る。

### 開始前

- 第1弾の告知を、オープンチャットとXに出す
- 勉強会の1枚を作る。題は Claude Code 実践。定員8人。5,000円。成果物は自分の作業を1つ自動化した記録
- 協賛の仮説を1枚にする。1回3万円。提供内容はゲスト15分と参加者への紹介
- 協賛候補は10社をリストにする。送るのは、実績が1回残ってから1社
- 申込フォームと請求のひな形を、勉強会の告知より先に公開する

### 1〜4週　商品を1回売る

| 週 | 企画 | 目的 | 最後に案内するもの |
| --- | --- | --- | --- |
| 1 | AIでエンジニアの仕事はなくなるか | 話題を作り、人を集める | 次回ライブ |
| 2 | フリーランスの年収と手取り | お金への関心の強さを見る | 次回ライブ |
| 3 | Claude Code 実践勉強会 | 最初の売上 | 勉強会の申込 |
| 4 | 直請けと営業のリアル | 協賛できる相手を見つける | 勉強会の残席。協賛の打診はライブの外 |

各回の翌日に、要約を3点出す。4週目のあと、協賛候補から1社に送る。

この4週の売上は勉強会だけを見る。8人で4万円。5人で2万5,000円。

### 5〜8週　2回目を売り、題を固定する

- 発言と投票が多かった題で、ライブをもう4回行う
- 勉強会を2回目開く。1回目の成果物を告知に使う
- 2回合計の申込が6人未満なら、価格を3,000円にするか、題をお金か案件に変えて3回目を行う
- 協賛の1枚には、その週の発言数、投票数、申込数を添える

### 9〜12週　本線を決める

- 協賛を1回実施するか、実施日を決める
- 月額会員の文面は、勉強会が2回売れてから書く
- 案件の仲介は、法令と届出の確認が終わるまで開始しない
- 91日目に、話題別の発言数、勉強会の人数と売上、協賛の打診数を1枚にまとめる

勉強会が売れていれば、それを本線にする。協賛が先に決まれば、勉強会と交互に置く。再生回数と登録者数は記録するが、第1期の合否には使わない。

## 10. 第1弾の告知文

最初に出す告知は、第1弾のAI回にする。このまま投稿できる。

```
今週のライブトークのお知らせ

AIでエンジニアは失業するのか

Claude、ChatGPT、Cursorなど、AIの開発ツールが急速に進んでいます。コードを書かせるだけでなく、アプリ開発やPC操作まで任せられるようになってきました。今回は、皆さんの実体験を聞きたいと思います。

話したいこと
- 仕事は減ったか、増えたか
- 単価は上がったか
- 仕事を任せることへの不安
- 5年後に必要な技能
- 今から学ぶなら何を選ぶか

肯定する人も、慎重な人も歓迎です。正解を決める場ではありません。使っている人、まだ使っていない人、これから学びたい人も参加できます。聞くだけの参加も歓迎です。
```

勉強会の告知は、第1回ライブのあと、反応を見てから出す。文面の核は次のとおり。

```
少人数の実践勉強会

Claude Codeを、自分の仕事に1つ使う

聞く回ではありません。90分で、自分の作業を1つ自動化し、その記録を残します。

- 自分の業務から、任せる作業を1つ選ぶ
- 差分の確認、テスト、修正前のメモの置き方
- 任せて失敗しやすい点
- 参加者がその場で手を動かす時間
```

## 12. 線引き

| 起きうること | 扱い |
| --- | --- |
| 所得や資産を聞きすぎる | 範囲で聞く。実額の公開は本人の意思に任せる。第10弾は仮定の話にする |
| 税金の雑談が助言に聞こえる | 経験談と冗談だと先に言う。正しい判断は税理士に渡す、と毎回添える |
| 意見の対立が人格の話になる | 論点を一言で言い直し、次の人に振る。運営は判定者にならない |
| 無料の場を有料で囲う | オープンチャットとライブの雑談は無料のままにする。料金は実践、資料、対面、企業との接点に付ける |
| 協賛金額を先に高く置く | 3万円は最初の仮説。1回実施した人数と反応を見てから上げる |
| 案件紹介が仲介事業になる | 対価を得て仕事をあっせんする前に、法令と届出を確認する。確認前はイベントの協賛までに留める |
| 準備が受託の稼働を圧迫する | ライブの準備は60分まで。10本の題はこの企画書で確定している |
| 月額を早く募ってしまう | 勉強会が2回売れるまで文面を作らない。第1期の売上目標に月額を入れない |
