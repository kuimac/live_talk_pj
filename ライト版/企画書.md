# 判断を残すライブ ライト版

フリーランスエンジニアのライブトークを、受託の稼働を合間に回す入口。方針は本編と同じで、第1期の作業だけを落とす。テーマの全体と企画10本は [本編/判断を残すライブ_企画書.md](../本編/判断を残すライブ_企画書.md) を見る。

期間は8週間。隔週1回、全部で4回。

## 位置づけ

オープンチャットは、気軽に質問でき、匿名でも本音が出る無料の入口のままにする。ライブは体験談と意見が交わる場にする。料金が付くのは、講師・教材・実践・成果物がある勉強会である。この8週間は売らない。

8週間終わったあと、要約が4回出て、発言が続いた題が1つあれば、本編の「Claude Code 実践・定員8人・1人5,000円」に進むかを決める。協賛、月額会員、個人向けの壁打ちの文面は、この版では作らない。

## やること

- 隔週1回、60分以内の無料ライブ。準備は30分まで。
- 翌日、オープンチャットとXへ3行だけ出す。各行は、その回に残った判断を1つ書く。
- ライブの最後の3分で案内するのは、次回ライブだけ。

## やらないこと

- 勉強会、協賛、短い記事、テーマ投票、月額会員、壁打ち。
- 申込フォーム、請求のひな形、協賛候補のリスト。

## 誰に届けるか

届ける相手は、フリーランスのエンジニアと、独立を考えているエンジニア。

| 場 | この版での使い方 |
| --- | --- |
| オープンチャット | 無料のままにする。告知はライブの案内だけ |
| X（@free_eng_live） | ライブの案内と、翌日の3行 |
| ライブ | 60分以内。出口は次回ライブだけ |

## 1回の進め方

本編第6節の5手で進める。問いは1本にする。

| 手 | やること | 第1回の例 |
| --- | --- | --- |
| 1 | 問いを投げる | AIで、エンジニアの仕事は減るか。 |
| 2 | 具体例を求める | 実際に仕事が減った人はいるか。 |
| 3 | 反対側を拾う | AIのおかげで仕事が増えた人はいるか。 |
| 4 | 一言で整理する | 実装は減り、設計とレビューは増える、という意見が並んだ。 |
| 5 | 次の問いに渡す | 今から学ぶなら、何を優先するか。 |

運営者が自分の結論を長く話すより、出た発言を拾って別の参加者に振る。意見が分かれても、人格の話にしない。論点を短く言い直して次の人へ渡す。

## 4回の題

本編の第1弾、第2弾、第3弾、第9弾を、この順で使う。

| 回 | タイトル | 核になる問い |
| --- | --- | --- |
| 1 | AIでエンジニアは失業するのか | 仕事がなくなる人と、稼げる人の違いは何か |
| 2 | 年収と手取りのリアル | 売上1,000万円でも、自由に使えるお金はいくらか |
| 3 | エージェントを使わず案件を取る | 直請けの最初の1件を、どうやって取ったか |
| 4 | 失敗談選手権 | 今なら笑える、現場での失敗は何か |

年収の回では、数字は範囲で聞く。実額の公開は求めない。失敗談の回では、そのあと何を変えたかを一つ聞く。

## 第1回の告知

最初に出す告知は、第1回のAI回。このまま投稿できる。

```
今週のライブトークのお知らせ

AIでエンジニアは失業するのか

Claude、ChatGPT、Cursorで、仕事は減ったか、増えたか。皆さんの実体験を聞きたいと思います。

話したいこと
- 仕事は減ったか、増えたか
- 単価は上がったか
- 今から学ぶなら何を選ぶか

正解を決める場ではありません。使っている人、まだ使っていない人、聞くだけの人も参加できます。
```

## 線引き

本編第12節と同じ線を、この版では4つにまとめる。

| 起きうること | 扱い |
| --- | --- |
| 所得や資産、税金の話になる | 範囲で聞く。実額は求めない。経験談だと先に言い、判断は税理士に渡す |
| 意見の対立が人格の話になる | 論点を一言で言い直し、次の人に振る。運営は判定者にならない |
| 無料の場を有料で囲う。協賛、月額、案件のあっせんを先に出す | この8週間は売らない。オープンチャットとライブは無料のままにする。仕事のあっせんはしない |
| 準備が受託の稼働を圧迫する | 準備は30分まで。題はこの4回で確定している |

## 8週目に見ること

毎週の数字は見ない。8週目に見るのは、実施回数、要約を出した回数、発言が続いた題が1つあるか。

要約が4回出て、発言が続いた題が1つあれば、本編の勉強会に進むかを決める。売上は、この版の判断には使わない。
